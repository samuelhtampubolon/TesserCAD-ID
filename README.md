# TesserCAD-ID

Initial repository test for TesserCAD-ID.

## Contents
- `hello.c`: C source code for test program.
- `hello.exe`: Compiled 64-bit Windows executable.

## Building and Running
To compile from source (using `zig cc` or any standard C compiler like `gcc` or `clang`):
```bash
zig cc -O2 -s hello.c -o hello.exe
```

To run:
```bash
./hello.exe
```
